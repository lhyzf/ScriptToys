# UI 方法热更新

`functions.ps1` 包含界面使用的辅助方法。保存修改后，运行中的界面会自动重新加载方法、读取配置并刷新任务操作区；已有任务和输出标签不会因此关闭。运行中的方法会在下一次调用时使用新版本。

此文件只能包含未指定作用域的函数定义。运行期间可以添加函数，但不能删除或重命名已加载的函数；这些变更需要重启界面。如果新文件存在语法错误或刷新操作区失败，会提示错误并保留上一次的方法和操作区。

窗口主体、已有输出控件以及 `main_ui.ps1` 中编译的辅助类型不会热更新，修改它们需要重启界面。已经执行的任务脚本也不会因修改 UI 方法而重新启动。

在项目目录运行热更新测试：

```powershell
pwsh -NoProfile -STA -File tests\ui_hot_reload.ps1
```
